The Silent Failures in Agentic Data Science

Xue Li, Hongqian Xia, Daniel Gomm, Aécio Santos, Cornelius Wolff, Madelon Hulsebos
Centrum Wiskunde & Informatica (CWI)
Paper Code

Abstract

Large language models have significantly lowered the barrier to writing code. Naturally, this has also led to the development of data science agents that promise automating the design and execution of data science from task formulation to model development. Existing evaluations of agentic data science (agentic DS) assess downstream predictive performance and code correctness, providing preliminary insight in agentic DS capabilities. We argue that these evaluations overlook the fundamental principles of data science: methodological data science- and domain knowledge. As such, only assessing downstream performance masks methodological failures such as data leakage and inappropriate validation, limiting the development of robust agentic DS systems. In this paper, we evaluate agentic DS beyond accuracy from three different angles: 1) a large-scale analysis of failure modes in common agentic DS frameworks and models across 220 data science tasks, 2) a reusable and extensible test suite with curated data science tasks that test for six specific failures in a controlled manner, and 3) a qualitative assessment of agentic DS pipelines against expert solutions on Kaggle competitions.

We find that the majority of agentic solutions contain at least one failure mode despite the complexity of agentic harness or model capacity. Moreover, we identify a positive correlation between the occurrence of data leakage failures and predictive performance, confirming the necessity to evaluate agents beyond accuracy. Our qualitative analysis shows that DS agents generally lack problem solving creativity and domain knowledge, compared to competition-winning data scientists. We believe that principled failure mode analysis, as presented here, should be integral part of agentic DS evaluations, and that the insights we surface will be key in developing trustworthy agentic DS pipelines.

Key findings

Which failure modes are most common?

Breaking failures down by mode shows which mistakes each agent and model makes most often.

Do failures inflate scores?

Leakage failure modes are associated with better predictive performance, while non-leakage failures go with worse performance. Predictive performance alone masks the silent failures.

Controlled test suite

Six curated tasks each probe one specific failure. More explicit hints lower fail rates for ReAct and AIDE, but not consistently for MLEvolve.

Agents vs. expert solutions

On five Kaggle challenges, no agent beats the 1st-place human solution on either the private or the public leaderboard.
